# MovieFrameSyncNode
Add-on for a node group that controls the framerate of videos and image sequences that are different to Blender Scene, allowing videos to run at realtime.

# Video Demonstration
[(Animating Pixel Art in Blender | My FREE Blender Add-on)](https://youtu.be/wmRecNDJULc)

# How to Use
1. Download MovieFrameSyncNode.zip OR download the MovieFrameSyncCode Folder and zip it

2. Open Blender -> Click Edit -> Preferences -> Add-ons -> Install from Disk -> Select Movie Frame Sync Zip Folder

3. Go to Shader Editor

4. Add New Node -> Search for MovieFrameSync (or should be under Texture)
![Movie Sync Frame Node](/MovieFrameSync%20Images/Movie%20Frame%20Sync%20Node.png)

5. Click Open to add video or click Load Image Sequence to well... load an image sequence

6. Click Detect FPS and it should sync up!
![Movie Sync Frame Node](/MovieFrameSync%20Images/Movie%20Frame%20Sync%20Detect%20FPS.png)

7. Enjoy!

Please let me know if there are any issues in the comments of the youtube video! I'm new to coding node groups and video sequencing at different framerates was a bit finicky so the tool isn't perfect but it accompishes what I needed from it and I thought it would be nice to share with everyone else.
