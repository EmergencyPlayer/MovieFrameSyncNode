# MovieFrameSyncNode
Add-on for a node group that controls the framerate of videos and image sequences that are different to Blender Scene, allowing videos to run at realtime.

# How to Use
1. Download MovieFrameSyncFiles.zip OR download the MovieFrameSyncFiles Folder and zip it

2. Open Blender -> Click Edit -> Preferences -> Add-ons -> Install from Disk -> Select Sync Them Lips Zip Folder
